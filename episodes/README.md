# Episodes and writing packs

**Start with [The Consequence Engine](consequence/episode.html).** It is a complete
15-scene, 3,055-word original fan screenplay built from an executed EFMW-inspired
simulation. It includes a cold open, three acts, a Smith-family subplot, and a tag.

The included sample was authored in the ChatGPT conversation from measured data.
It was not produced by an executed API call. The separate API integration can
generate additional scripts once configured locally.

In `consequence/`, `episode.fountain` is the screenplay; `script.json` includes
per-scene evidence references and fictional bridges; `audit.json` links those
references to actual measurements; `run.json` is replayable. `provenance.json`
records the origin honestly. The HTML reader is self-contained and printable.

`series/` contains six additional **prompt packs**, not completed episodes:

| Experiment | Optional story direction |
|---|---|
| Portal | A commute that keeps returning to its starting problem |
| Curve | A gated multiverse discovers that opening access changes who bears the cost |
| Memory | A relocation service confuses a new address with a fresh history |
| Decoherence | A quieter multiverse is mistaken for an emptier one |
| Field | A brief impulse outlives the decision that caused it |
| Feedback | A navigation system reshapes the conditions it tries to navigate |

Each pack contains an executed t = 8 replay, a measured dossier, an LLM prompt,
and its output schema. No show footage, art, or copied episode dialogue is included.

these original fan works are unofficial and do not assert endorsement.
