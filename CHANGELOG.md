# Changelog

## 1.1.0 — 2026-10-11

- Added measured-dossier extraction, a structured LLM prompt, and scene validation.
- Added a Node-only OpenAI Responses adapter with refusal, timeout, incomplete-output, and error handling. No key is placed in the browser.
- Added the episode-writer UI, prompt/replay downloads, script import, and evidence inspection.
- Executed a 14-unit consequence scenario and authored a complete 15-scene fan episode from its results; live API generation was not used.
- Added six executed prompt packs, Fountain/HTML/JSON exports, scene audits, and generation provenance.
- Kept numerical engine 1.0.0 and existing replay compatibility unchanged.

## 1.0.0 — 2026-10-11

- Six interactive experiments, including guided boundary, record, and jump events.
- Shared browser/Node density-matrix engine and normalized scalar wave solver.
- Live controls, exact state replay, CSV measurements, and per-experiment ablations.
- Offline interface, accessible measurement tables, and responsive layout.
- CLI, numerical validation, CI, and optional GitHub Pages workflow.
- Explicit model specification, scientific claim boundaries, source provenance,
  and extension guidance.
